# Code of Conduct

## The short version

Be decent. Assume good faith. Keep discussion on-topic.

## The longer version

This is a small community around a single plugin. Keep the tone
professional and constructive so people actually want to file bugs and
ask questions here.

### Expected

- **Be respectful** in issues, PRs, and discussions. Disagreement is
  fine; disrespect isn't.
- **Assume good intent** when reading someone's message. Text strips
  tone; default to the charitable reading.
- **Stay on topic**. Questions about unrelated UE plugins, general VP
  setup advice, etc. belong elsewhere.
- **Use the right place**: Issues for bugs, Discussions for questions
  and ideas.

### Not acceptable

- Personal attacks, harassment, or discriminatory language — on any axis.
- Sexualized content.
- Posting other people's private information.
- Persistent off-topic or low-effort spam.
- Piracy — including posting plugin binaries, sharing license keys, or
  discussing how to circumvent Fab's distribution.

### Enforcement

Reports go to the maintainer via the email address on the Fab listing.
Possible outcomes, roughly in order of severity:

- Private message / warning
- Public reply asking for a reset
- Editing or removing the offending content
- Temporary interaction block
- Permanent ban from this repo

Enforcement is at the maintainer's discretion; the goal is a repo that
stays useful and welcoming, not rulebook compliance.
